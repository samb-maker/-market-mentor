MARKET MENTOR

This is a simple installable web app prototype.

FILES
- index.html
- manifest.json

FASTEST WAY TO TEST
1. Put these files on any static web host such as GitHub Pages, Netlify, or Cloudflare Pages.
2. Open the resulting HTTPS address in Safari on your iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Launch Market Mentor from the new icon.

The first version is intentionally self-contained and does not require an API key.
